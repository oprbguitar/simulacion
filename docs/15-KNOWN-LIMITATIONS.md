# Limitaciones conocidas

1. Los valores de costo son seeded/mock, no datos reales conectados.
2. La escena es SVG 2.5D; aún no hay R3F, GLB ni `model-viewer`.
3. El MVP muestra una selección de etapas de construcción, no las 27 fases completas de obra profesional.
4. La hipoteca, el roof/slab y la electricidad se representan como opciones/impactos iniciales, no como ingeniería, metrados ni dimensionamiento.
5. El timeline usa hitos mensuales simplificados; no ofrece aún zoom libre año/mes ni drag.
6. `/_studio` no tiene autenticación y debe permanecer local.
7. La verificación de la UI se ejecuta localmente con Playwright; no hay confirmación de una URL pública.
